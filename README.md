# Turbo Details — Website Institucional

Website institucional desenvolvido para a Turbo Details, empresa de estética automotiva.

O projeto foi desenvolvido com foco em apresentar a marca, seus serviços e sua identidade visual através de uma interface moderna, responsiva e otimizada para diferentes dispositivos.

## Sobre o projeto

O website foi criado para fortalecer a presença digital da Turbo Details e oferecer aos clientes uma experiência mais completa de navegação e apresentação dos serviços.

A aplicação possui uma estrutura baseada em componentes e rotas, permitindo maior organização e facilidade de manutenção e evolução do projeto.

## Funcionalidades

* Apresentação da empresa e identidade visual
* Apresentação dos serviços de estética automotiva
* Interface responsiva para desktop e dispositivos móveis
* Navegação estruturada por rotas
* Componentes reutilizáveis
* Interface moderna e interativa
* Animações e transições
* Organização modular do projeto

Desenvolver uma presença digital profissional para uma empresa de estética automotiva, combinando apresentação de serviços, identidade visual e experiência de navegação em uma única aplicação web.
